# Corpora for running-key and primer search

Not committed; download before use.

## gutenberg_english.txt
Cleaned, deduplicated Project Gutenberg corpus, ~100 MB. Used to build the
hexagram fitness table and as a sanity reference for English-ness scoring on
short (~73 character) strings.

## carter_tutankhamen.txt
Howard Carter, *The Tomb of Tut-ankh-Amen* (Griffith Institute, Oxford). This
is the confirmed source of K3's plaintext paraphrase, which makes it the
single strongest running-key candidate for K4. K2's "LAYER TWO" matches
Carter p.170 "what we may call the second layer".

    https://www.griffith.ox.ac.uk/discoveringtut/

## schliemann_memoirs.txt
Heinrich Schliemann's memoirs (Sanborn-favorite per the 2009 Berman oral
history). Worth trying as a running-key candidate.
